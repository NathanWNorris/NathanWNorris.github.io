Data handling

Privacy policy

Last updated: October 8, 2026

This policy describes the owner-operated Agent Hub – Badly Drawn History workflow, maintained by Nathan Norris. It covers the local app’s YouTube connection and this informational website.

Google data the app accesses

With the channel owner’s consent, the app requests youtube.upload and youtube.readonly permissions. Its current YouTube adapter reads channel ID, channel name and uploads playlist information; checks uploads and video IDs; and reads video titles, descriptions, tags, privacy, publication scheduling and processing status. It sends the owner-approved video, thumbnail and publication metadata to YouTube. Google’s consent screen describes the scope of the permissions being granted.

Purpose and sharing

The app uses Google data to identify the correct channel, prevent duplicate releases, upload approved videos, verify publication details and diagnose connection or publishing failures. Necessary workflow status and publishing metadata can be viewed by the owner and the assistants the owner authorizes to operate the workflow. OAuth credentials are handled by the local Google worker and are not returned to model tools.

Video production and review may send owner-authorized scripts, audio, images and candidate videos to the selected creative or review providers. Those services have their own policies. This does not require sharing OAuth tokens with them. Google user data is not sold, used for advertising or used to train general-purpose AI models.

Agent Hub – Badly Drawn History’s use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and retention

OAuth client configuration and access/refresh credentials are saved on the owner’s Windows PC using Windows Data Protection API protection. Connection state, upload receipts, channel/video metadata and workflow evidence are retained in local app-owned files and databases. Production media is stored in the owner’s episode workspace. Local records remain until the owner removes them; there is no automatic retention deadline represented by this policy. The public website contains no OAuth credentials, account receipts or unpublished production media.

Disconnecting and deletion

The owner can revoke Google access at Google Account connections. A revoked or expired grant requires reconnection and channel verification before publishing resumes. Revoking access does not itself delete local records or videos already uploaded to YouTube. To request deletion of local connection or workflow records, contact the operator through NathanWNorris on GitHub. The owner can manage uploaded videos separately in YouTube Studio.

This website

This static informational site has no sign-in form, analytics code or tracking scripts added by the operator. GitHub Pages hosts the site and logs visitor IP addresses for security purposes, as described by GitHub Pages and the GitHub Privacy Statement. Following an external link takes you to that service’s own website and policies.

Changes and contact

This policy will be updated when the app’s data practices change. For questions or data-handling requests, contact Nathan Norris through NathanWNorris on GitHub.
